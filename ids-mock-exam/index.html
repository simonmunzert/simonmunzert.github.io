How it works

  • Single choice. Exactly one of the four options is correct. True/false statements count as single choice with two options.
  • Mark lines. You get a short snippet of R code, shell commands, HTML or plain strings. Tap or click the line(s) the question asks for, e.g. the line that contains a bug, the elements an XPath expression selects, or the strings a regular expression matches. A question only counts as correct if you mark exactly the right lines.
  • Scoring. One point per question. Unanswered questions count as wrong.
