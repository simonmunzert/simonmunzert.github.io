# Der Daten-Lifecycle – Kurswebseite

Statische Webseite zu Modul 2 „Der Daten-Lifecycle“ des Zertifikatsprogramms „KI und Data Science für die öffentliche Verwaltung“ (Hertie School, 26.–28. Oktober 2026). Online unter https://simonmunzert.com/zertifikat-daten/

Die Seiten werden mit `build.py` aus den Daten im Skript erzeugt (danach wie gewohnt committen und pushen):

```
python3 build.py
```

Folien und Code-Materialien liegen im Repository [hertie-ai-certificate/modul-2-2026](https://github.com/hertie-ai-certificate/modul-2-2026) und werden über raw.githack.com bzw. GitHub direkt verlinkt.
