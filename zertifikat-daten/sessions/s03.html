Tagesthema: Der Daten-Lifecycle und: Woher kommen Daten?

Folien (HTML)Quelltext (Rmd)Ordner auf GitHub

Inhalte

In dieser Session geht es um die konkrete Gestalt von Daten und darum, wie sie gewonnen, ausgetauscht und bereitgestellt werden. Wir beginnen bei der wohl verbreitetsten Form der Datenhaltung in der Verwaltung, dem Spreadsheet, und besprechen, was gute von schlechten Tabellen unterscheidet. Anschließend lernen wir mit XML und JSON die gängigen Austauschformate für strukturierte Daten kennen, werfen einen Blick auf relationale Datenbanken und auf die XÖV-Standards der öffentlichen Verwaltung (etwa XFall). Abschließend diskutieren wir, was es heißt, Daten so zur Verfügung zu stellen, dass andere sie tatsächlich nachnutzen können.
